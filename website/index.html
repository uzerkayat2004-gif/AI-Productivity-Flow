Privacy

Local-first, and honest about it

Flow is a desktop app, not a thin client for someone else's server.

Audio stays on your machine

Transcription runs locally through Whisper unless you deliberately choose a cloud speech provider.

Keys never leave your disk

Credentials are encrypted in a local SQLite database. There is no telemetry endpoint collecting them.

Nothing is sent without asking

Your text only reaches an external model when you pick that model and authorise the request.

Get started

Install Flow

Install Flow instantly using a single terminal command. Sets up an isolated environment, configures speech models and rendering engines, and registers dual-layer background auto-startup.

PowerShell (Run as User — No Admin Required) 
# One-liner automated installation for Windows 10/11 x64
irm https://raw.githubusercontent.com/uzerkayat2004-gif/AI-Productivity-Flow/main/scripts/install.ps1 | iex
Terminal (macOS 12+ Apple Silicon & Intel) 
# One-liner automated installation for macOS
curl -fsSL https://raw.githubusercontent.com/uzerkayat2004-gif/AI-Productivity-Flow/main/scripts/install.sh | bash
Important Note for macOS Users

macOS support is currently in Community Preview / Experimental mode and has not yet undergone comprehensive physical device QA. You might experience hotkey quirks, audio permissions dialogs, or minor bugs. Windows remains our fully verified production tier. If you encounter any issues on Mac, please help us improve by reporting them on GitHub!
